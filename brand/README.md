## Asset pool

```text
brand/
├── logos/       Canonical symbol, lockups, monochrome marks, and app icon
├── icons/       PNG exports for app, profile, touch, and favicon use
├── patterns/    Reusable catalog-grid artwork
├── social/      Channel-ready LinkedIn, Open Graph, and GitHub images
├── templates/   Editable SVG layouts for recurring campaigns
├── tokens/      JSON, CSS, and TypeScript brand tokens
└── visuals/     Brand-system overview board
```

## Quick rules

- Style the name as **awalogo**, always lowercase.
- Use the full-color symbol by default.
- Use the square app icon only where a container is required.
- Keep one-quarter of the symbol’s height clear on every side.
- Do not imply that awalogo owns, represents, or is endorsed by institutions
  whose trademarks appear in the catalog.
- Do not describe every catalog asset as verified. Prefer “source-aware,”
  “reviewed,” or “sourced from official properties” when accurate.

Logo artwork for cataloged institutions remains the property of its respective
owners. See [`TRADEMARKS.md`](../TRADEMARKS.md).
