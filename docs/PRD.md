# Nigerian Bank & Fintech Logos PRD

## Summary

Create an open source logo library for Nigerian banks and fintechs, starting
with a Figma plugin and using a structured logo data package underneath it.

## Users

- Designers who want searchable, insertable SVG logos in Figma.
- Developers who want clean, optimized SVG assets.
- Contributors who can add or correct verified assets.

## v1 Scope

- Searchable Figma plugin.
- Versioned runtime catalog shared by the website and Figma plugin.
- Logo metadata with name, category, aliases, source, status, and SVG path.
- Validation for metadata, duplicate slugs, missing files, and unsafe SVG.
- Contribution workflow and trademark policy.

## Later Scope

- Published npm package.
- React component package.
- Iconify-compatible export.
- Generated documentation gallery.
- Larger verified catalog across commercial banks, MFBs, fintechs, and payment
  providers.

## V2 Preview Status (18 October 2026)

The original scope above describes V1. V2 now adds Nigerian companies across
industries and reviewed African companies using an independent catalog, plus
249 country/territory flags. It remains Coming soon; V1 and the current plugin
retain their existing 228-logo catalog. The combined V2 collection has 312 companies.

Implemented: normalized and former-name search, multi-category/industry/market
filters, popularity sorting, 20-item default pagination, separate sourced/name
recommendations, asset panels, reporting, primary request actions, floating
pack/drop bag with undo, mixed ZIPs, themes, five languages, shortcuts and sound.
Flags share relevant browsing and collection behavior, with region/name/code search.

See the [user guide](v2-guide.md) for precise behavior and the
[delivery plan](v2-product-and-delivery-plan.md) for unfinished owner publishing,
colors/guidelines, SEO and plugin compatibility work. This status is not a launch claim.
