# Roadmap

## Current V2 Preview (18 October 2026)

The milestone headings below preserve the original roadmap; they are not release
announcements. Current implementation is documented in the [V2 guide](v2-guide.md).

Implemented in the Coming soon preview: independent Nigerian/African company
expansion, flags, source-aware historical artwork, popularity and multi-filter
browsing, default pagination, search suggestions, draggable pack/drop collection
with bulk undo, code/download/share workflows, logo reports, localized interface,
themes, compact controls, contextual shortcuts and persisted action sound settings.

Still pending: fluent translation review, final browser/mobile/audio verification,
production smoke tests and launch approval; owner claims/publishing, brand colors,
PDF guidelines, SEO/prerendering, and V2-compatible plugin support. Existing V1
assets and plugin behavior are preserved.

## 0.1 Foundation

- Monorepo scaffold.

- Verified seed SVG catalog.
- Validation and CI.
- Contribution and trademark docs.
