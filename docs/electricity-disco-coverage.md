# Nigerian Electricity DisCo Assets — 19 October 2026

## Scope

This batch covers all **11 regional successor DisCo identities**, plus **Aba
Power**, the independent ring-fenced distribution operator. It is not a claim to
cover every private distribution network or newly incorporated state subsidiary.
Nigeria's state-market transitions mean that historical franchise areas should
not be presented as current exclusive territories.

Operator scope is checked against the
[NERC licensee directory](https://nerc.gov.ng/need-help/services/licencees/),
[BPE's regional company list](https://www.bpe.gov.ng/electric-power/), and
[NERC's Aba Power material](https://nerc.gov.ng/wp-content/uploads/2024/11/Aba-Power-Electricity-Distribution-Plc.-Monthly-Energy-Cap-November-2024.pdf).
Original sources, evidence and review decisions are retained in the brand manifest.

## Sourcing and Compatibility

All 12 logos were visually reviewed from official operator sites. BEDC and Aba
Power expose header artwork through application bundles; EEDC uses a CSS
background image. Payment-provider/partner artwork is not approved as an
operator identity. Source bytes are preserved; PNG/WebP are generated without
upscaling raster originals, with SVG only for genuine source vectors.
Kaduna's official `.svg` is a container for an embedded PNG. The original PNG
bytes are extracted and offered as PNG/WebP, not misrepresented as vector art.

Previews, details, downloads, sharing, reporting and the mixed-asset bag reuse the
existing V2 workflow. All 104 pre-existing expansion records are snapshotted in
`disco-baseline.json`. Legacy files and the approved MoMo V2 correction remain
unchanged. This batch brings the local V2 company total to 344.

State subsidiaries such as MainPower are separate identities, not aliases for
their parent DisCo. Further state-level assets require their own sourcing and
review; they are not silently counted as covered by a parent logo.

No production deployment or Figma Community release is part of this addition.
